# Your Pi — the one-page version

Keep this with the box. The full guide has more detail, but this page is usually
all you need.

## 1. Plug it in

Put the Pi somewhere dry with a little air around it. If you are using a network
cable, plug that in **first**, then the power. Wait two minutes.

## 2. Get it online — pick one

- **Network cable (easiest).** Plug it in. Nothing else to do.
- **Wi-Fi.** On a phone or laptop, join the network called **QConnect-Setup**. A
  page opens by itself; if it doesn't, open a browser and type **10.0.0.1**. Pick
  your Wi-Fi, type the password, press Save. The Pi restarts and joins.
- **Mobile SIM.** Already set up. Just power it on and give it ten minutes.

## 3. How to tell it worked

A steady light and a blinking light. Nothing else has to happen on your side — we
can see it arrive on our dashboard within a couple of minutes.

## 4. Everyday use

Leave it plugged in and leave it alone. It updates itself. If you need to move
it, pull the power, move it, plug it back in.

## 5. The one rule

Never pull out the little memory card while the Pi is powered on, and never erase
or rewrite it — even if another device asks you to.

## 6. Something not right?

| What you see | Try this |
|---|---|
| No lights | Push the plug fully in at both ends; try another socket. |
| Red light only | Power off, push the memory card fully in, power back on. |
| No QConnect-Setup network | Power off, wait ten seconds, power on, wait two minutes. |
| Was working, now offline | Did the Wi-Fi password change? Redo step 2. On a SIM unit, move it near a window. |
