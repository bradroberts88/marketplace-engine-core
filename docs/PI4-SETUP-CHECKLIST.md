# Two Pi 4s — tick sheet

Keep this next to the laptop. Full instructions are in the first-time setup
guide; this page is just so you don't lose your place.

Date: ______________  Done by: ______________

## Before you start

- [ ] Raspberry Pi Imager installed on the laptop
- [ ] Card reader working
- [ ] Wi-Fi name and password written down (optional but helpful)
- [ ] Network cable available (optional)
- [ ] Fleet system switched on, so cards can register

## Pi one — name: ________________  dealership: ________________

- [ ] Power unplugged, memory card taken out
- [ ] Card erased (Imager → Erase)
- [ ] Raspberry Pi OS Lite 64-bit written, customisation settings cleared
      (including anything about SSH / remote access — leave it off)
- [ ] Card removed and reinserted; bootfs drive visible
- [ ] Prepare-Card.ps1 run, ended with "This card is ready."
- [ ] Card ejected safely and put back in the Pi
- [ ] Cable plugged in first (if using one), then power
- [ ] Waited four minutes through the automatic restart
- [ ] Appears online in the dashboard — connected by: cable / Wi-Fi / SIM
- [ ] Name written on the case

## If a box is not ticked

Do not ship that Pi. A Pi that half-works on the bench never works at a
dealership. Call QCAI Support on 1-855-782-6824 with the name on the case.
